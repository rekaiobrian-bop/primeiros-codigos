# Meu primeiro código

Este foi o primeiro código que escrevi enquanto aprendia Python.

Nele, aprendi o conceito de variáveis e usei `if` para verificar o nome digitado. Se eu digitar `kaio`, o programa responde:

```text
ola kaio!!
```

Também usei `end=" "` no primeiro `print` para testar como juntar duas chamadas de `print` na mesma linha.

## Como executar

Com o Python instalado, execute no terminal:

```bash
python main.py
```
